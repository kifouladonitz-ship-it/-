## 3. Как открыть
**Что сделать проверяющему?**
1.  Открыть репозиторий на GitHub.
2.  Перейти в папку `notebooks/`.
3.  Нажать на файл `lr01_runtime_order_KifoulaLobel.ipynb`.
4.  Для запуска: нажать кнопку `Open in Colab` или скачать и запустить локально в Jupyter.

## 4. Проверка
**Как понять, что всё работает?**
Запустить все ячейки в notebook. 
Ожидаемый результат: в выводе появляется текст `Environnement prêt` и версия Python. Ошибок быть не должно.

## 5. Ограничения
**Что не проверяется или может сломаться?**
1.  Проект рассчитан только на Python 3.10+.
2.  Для работы в Colab требуется подключение к интернету.
3.  Не проверяется установка внешних библиотек, кроме стандартных.
