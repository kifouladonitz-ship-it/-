## L Политика публикации файлов

1. Файлы РАЗРЕШЁННЫЕ к публикации на GitHub
Эти файлы являются публичными и не содержат рисков:
- Код: `.ipynb`, `.py`, `.R` - код из наших notebook
- Документация: `README.md`, `version_log.md`, `text_card.md`
- Примерные данные : файлы `.csv` с вымышленными данными для обучения
- Структура проекта : папки `notebooks/`, `data/`, `docs/`

2. Файлы ЗАПРЕЩЁННЫЕ к публикации
Эти файлы содержат конфиденциальные данные и НИКОГДА не должны выкладываться на GitHub:
- Персональные данные : ФИО, адрес, email, номер телефона, фото
- Реальные данные студентов : оценки, результаты, списки групп
- Идентификаторы: пароли, токены, API-ключи, файлы `.env`
- Тяжёлые файлы: полные базы данных, видео

 3. Основное правило
Если информация может идентифицировать реального человека → публиковать нельзя.
