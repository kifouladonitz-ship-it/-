*Сравнение: GitHub Web против Архива ZIP*

*1. Таблица преимуществ и недостатков*
Критерий	**GitHub Web**	**Архив ZIP**
**Воспроизводимость**	**Высокая**
Есть вся история коммитов, `version_log.md`. Видно кто, что и когда менял. Можно откатиться к любой версии.	**Средняя**
Только финальная версия. Истории изменений нет.
**Риск ошибочной публикации**	**Высокий**
Можно случайно запушить личные данные, пароли, ключи API, или не ту ветку.	**Низкий**
Ты сам вручную проверяешь что лежит в zip перед отправкой.
**Совместная работа**	**Высокая**
Peer review, Issues, комментарии, Pull Request. Удобно работать командой.	**Отсутствует**
Это статичный файл. Комментировать и править нельзя.
**Доступ и зависимость**	**Нужен интернет**
Если GitHub упал = сдать работу нельзя.	**Независим**
Работает оффлайн. Можно отправить по почте/WhatsApp/Moodle.
**Отслеживаемость**	**Высокая**
Каждый коммит подписан датой и автором.	**Низкая**
Только одна дата создания архива.
**Удобство проверки преподавателем**	**Высокое**
Можно смотреть код прямо в браузере, запускать Actions.	**Среднее**
Нужно скачать и распаковать.

## Вывод
GitHub лучше для разработки, командной работы и долгосрочного хранения. 
ZIP лучше как "план Б" и для контролируемой сдачи работы.
Идеально: Разрабатывать на GitHub, а сдавать ZIP как резервную копию.
